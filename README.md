# Flappy Bird

A simple Flappy Bird game created with HTML, CSS, and JavaScript.

## How to Play

1. Open the `index.html` file in your web browser.
2. Press any key to make the bird flap its wings.
3. Navigate the bird through the gaps in the pipes to score points.
4. If the bird hits a pipe or the ground, the game is over.

## Running the Game

No special setup is required. Simply open the `index.html` file in a modern web browser to start playing.
